# PixVault Native 更新履歴

## 0.9.0-alpha.1 — 2026-10-26

### Added

- WebViewを使用しないWindows専用C# / WPFビューアの初期プレビュー。
- 画像、ZIP/CBZ、自然順の隣接ファイル移動、見開き・右綴じ・ページシーク。
- 通常ホイールでファイル移動、Ctrl＋ホイールで25〜400%の拡大縮小。
- NeeView風の暗い背景・隙間なし見開きと、標準表示の切り替え。
- 独立した設定保存、ページ容量・画素数制限、古い非同期読込結果の破棄。

### Known limitations

- 現行Tauri版の代替となる完成版ではない。動画、PDF、ライブラリ、検索、タグ、AI、データ移行等は未実装。
- WPF実画面の表示・マウス操作・DPI・インストールは未確認。CLIビルドと非GUIテストのみ実施する。
- 未署名のポータブルプレビューとして配布。OSの関連付けや現行版のDBは変更しない。
