# PixVault Native 仕様書 v0.9.0-alpha.1

作成日: 2026-10-26

## 構成

C# / .NET 10 / WPF。画面にHTML・JavaScript・WebViewは使わない。CoreはUI非依存、NativeはWPFとWindows画像デコーダを利用する。既存Tauri版とは別アプリのプレリリース版数を持つ。既存版の版数定義・DBを変更しない。

## 入出力

- PNG/JPEG/BMP/GIF静止フレーム、ZIP/CBZ内の同形式に対応。ZIPのディスク展開は行わない。
- ファイル選択ダイアログ、ドラッグ＆ドロップ、起動引数の先頭パスで開く。
- 同一フォルダー内の対応ファイルを数字部分を考慮した自然順に列挙。ホイール下で次、上で前。端では停止し、260ms以内の連続移動を抑制。
- Ctrl＋ホイールは25〜400%ズーム。倍率ボタンで100%の画面フィット。別ファイルを開くと100%へ戻す。拡大時はスクロールバーで移動。
- ページボタン、スライダー、左右キーでページ移動。右綴じの左右キーは読む方向に対応。Ctrl＋左右はファイル移動。
- 見開きは偶数インデックス起点で2ページ。右綴じは右側に先のページ。奇数最終ページは単ページ。

## 外観・保存

- 初期状態は見開き・右綴じ・NeeView風。標準へ切り替え可能。
- NeeView風は暗い中立色背景、見開き間隔なし。既存版のテーマやNeeViewの全機能は再現しない。
- 設定は `%LOCALAPPDATA%/PixVault.Native/reader-settings.json` へ一時ファイル経由で保存。破損時は既定値。
- 現行PixVaultのライブラリDB、タグ、お気に入り等へはアクセスしない。

## 安全性・制約

- 1ページ64MiB、1画像1億画素、1アーカイブ20,000ページまで。表示用デコードは長辺2560pxまで。
- 非同期デコードを直列化し、要求世代で古い結果を破棄。ファイルハンドルは読込後に解放。
- 動画、PDF、RAR/7z、WebP/AVIF、GIFアニメーション、ライブラリ・検索・タグ・AI・データ移行は未対応。
- コアと画像デコードの非GUIテストおよびビルドを検証。実画面、DPI、物理入力、導入試験は未確認。

## 配布

win-x64の.NETランタイム同梱ポータブルフォルダーを版数入りZIPに格納。署名・ファイル関連付け・インストーラーはこの初期プレビューに含めない。現行版と並行して評価する。
