# PixVault for Windows アプリ仕様書 v0.7.5

更新日: 2026-09-14。対象: Windows 10/11 x64。以下以外はv0.7.4の仕様を継承する。過去版の成果物・仕様書は保持する。

## 動画の再生開始判定

- libVLCのDirect3D11ネイティブ出力では、動画サイズ（幅・高さ）が取得でき、再生状態または一時停止状態になった時点でビュワーを再生可能とする。
- `libvlc_media_get_stats().displayed` は描画経路やハードウェアデコーダーによって0のままになる場合があるため、再生開始の必須条件にしない。
- 動画サイズ自体が30秒以上取得できない場合は、従来どおり再生エラーとして通知する。
- 動画ファイルは変換・置換せず、カタログで解決した実ファイルをそのまま再生する。

## 確認方法と未確認事項

- `pnpm run typecheck`、`pnpm run test:video-playback`、`cargo check --manifest-path src-tauri/Cargo.toml` を実行する。
- 再生開始判定の回帰テストで、表示フレーム統計が0でも幅・高さと再生状態があれば再生可能になることを確認する。
- PC画面操作禁止の規則に従い、指定動画を実アプリで表示した目視確認とインストーラーGUIは未確認。コード署名証明書がないため、WindowsインストーラーはAuthenticode未署名。
