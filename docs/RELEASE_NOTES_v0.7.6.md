# PixVault for Windows 0.7.6

## 修正内容

- メディア設定時にlibVLCの既定表示へ戻る場合があるため、動画を設定した後にも自動スケールと元のアスペクト比解除を再適用します。
- これにより、一部の動画で上部・下部が切れて表示される問題を抑止します。

## 配布物

Windows 10/11 x64では`PixVault.for.Windows_0.7.6_x64-setup.exe`を使用してください。動画ファイルは変換せず、同梱libVLCで再生します。

PC画面を使った目視確認はプロジェクト規則により実施していません。コード署名証明書がないため、WindowsインストーラーはAuthenticode未署名です。
