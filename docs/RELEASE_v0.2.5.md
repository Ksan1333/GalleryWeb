# PixVault for Windows 0.2.5 — 検証版

2026-09-05 / Windows x64 / DBスキーマ9

## 主な変更

- ファイルから開くと「全フォルダー」でその親フォルダーを表示。その一覧内のビュワーで開き、閉じても最後に見ていた場所へ戻る。
- 右綴じブックのシークを右から左へ統一。目印・プレビュー・左右キーも一致させ、左綴じと動画の方向は維持。
- 外部改名・同一ボリューム内移動で整理情報を保持するため、Windowsファイル識別情報を記録。
- ブックの派生キャッシュを容量・件数・期限で管理。原本は回収対象外。
- 設定・診断の入口を復旧し、表示サイズ、選択中の閲覧、フォーカス、ホームの削除後移動、フォルダー履歴を改善。
- 未使用CSSを削除。PDF.js 6.2.108、PostCSS 8.5.28、nanoid 3.3.18へ互換範囲で更新。

詳細は同じタグのCHANGELOG.mdとdocs/APP_SPECIFICATION_v0.2.5.mdを参照。

## 既知の制約・未完了範囲

- 画面操作禁止ルールにより、Windows 10/11での手操作によるインストール・関連付け選択・実機UIの見た目は未確認。
- 除外したRust4件は、大容量AIモデル・公開X/FxTwitter/CDN・外部GIF素材を必要とするテスト。
- ファイル識別情報の保持は更新後に記録した実体が対象。過去の改名、非対応ファイルシステム、別ボリューム移動を推測で統合しない。更新後に対象フォルダーを再読み込み/スキャンする。
- DB8→9へ移行する。旧EXEへ置き換えるだけでDBも戻せるとは保証しないため、必要に応じて更新前カタログをバックアップする。
- 複数の外部ファイルを渡した場合、閲覧対象は開始ファイルの親フォルダーとなる。異なる親をまたぐ受け渡し順リストではない。
- 大規模なクエリ全件選択、ホーム全面刷新、旧UI/巨大モジュールの最終整理、キャッシュ使用量/手動回収UIは次フェーズ。
