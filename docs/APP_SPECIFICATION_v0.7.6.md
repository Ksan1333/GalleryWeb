# PixVault for Windows アプリ仕様書 v0.7.6

更新日: 2026-09-14。対象: Windows 10/11 x64。以下以外はv0.7.5の仕様を継承する。過去版の成果物・仕様書は保持する。

## 動画の表示比率

- libVLCのネイティブ出力へ動画を設定した後にも、スケール自動調整（0）とアスペクト比上書き解除を適用する。
- メディア設定時にVLCのビデオ出力モジュールが既定値を再適用しても、動画の元の比率を使ったネイティブ表示領域が維持される。
- 動画ファイルは変換・置換せず、カタログで解決した実ファイルをそのまま再生する。

## 確認方法と未確認事項

- `pnpm run typecheck`、`pnpm run test:video-playback`、`cargo check --manifest-path src-tauri/Cargo.toml` を実行する。
- Rust側のネイティブ表示比率設定がメディア設定後にも呼ばれることをコードレビューで確認する。
- PC画面操作禁止の規則に従い、指定動画を実アプリで表示した目視確認とインストーラーGUIは未確認。コード署名証明書がないため、WindowsインストーラーはAuthenticode未署名。

## 配布物

ビルド後に`release/0.7.6`へ版数入りインストーラー、対応libVLCソース、通知文、チェックサムを保存する。過去版の配布物は保持する。
