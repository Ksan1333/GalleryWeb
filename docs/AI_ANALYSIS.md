# AI分析

PixVault for Windows のAI分析は、Android版と同系統の
`SmilingWolf/wd-v1-4-moat-tagger-v2` をONNX Runtimeでローカル実行します。
分析対象の画像を外部APIへ送信することはありません。

## 初回ダウンロード

AI分析を初めて開始したときだけ、モデルとタグ定義（合計約311.3 MiB）を
Hugging Faceからユーザーのローカルアプリデータへ取得します。インストーラーには
モデルを含めないため、通常のアプリ配布サイズはモデル分だけ増加しません。

- モデル: `model.onnx`（326,197,340 bytes）
- タグ定義: `selected_tags.csv`（253,906 bytes）
- 固定リビジョン: `8452cddf280b952281b6e102411c50e981cb2908`
- ライセンス: Apache-2.0

取得後はサイズとSHA-256を検証し、不一致のファイルを推論には使用しません。
初回取得中と分析中は進捗が表示され、キャンセルできます。モデル取得には
インターネット接続が必要ですが、検証済みモデルの取得後はオフラインで分析できます。

## 対象と保存方法

- カタログ内の画像とGIFを分析します。全期間、直近7・30・90日、今年、任意の開始日・終了日で期間を指定できます。
- 登録フォルダーと相対サブフォルダーを指定し、下位フォルダーを含めるか選択できます。画面に読み込み済みの項目だけでなく、SQLiteカタログから条件に一致する全件を抽出します。
- GIFは代表フレーム（先頭フレーム）を使用します。
- 縦横比を維持した白余白、448×448、BGR/NHWCというモデル公式実装に合わせた前処理です。
- **標準分析:** 信頼度0.60以上から上位40件を保存します。従来の分析設定と互換です。
- **詳細分析:** Danbooru系の細粒度タグを、一般・キャラクター・作品・作者・メタへ分類して
  最大120件保存します。一般・メタなどは信頼度0.35以上、作者・作品・キャラクターは
  0.45以上が対象です。
- 詳細分析ではタグ名、分類、実際の信頼度をSQLiteへ保存し、完了画面に分類別件数と
  最後に成功した画像の上位12タグを表示します。
- ratingカテゴリの `general` / `sensitive` / `questionable` / `explicit` を
  SFW / R15 / R18へ変換します。
- 再分析時に置き換えるのは `source=ai` のタグだけです。手動タグは保持します。
- 手動で設定した年齢区分もAIでは上書きしません。
- キャンセルはモデル取得・SHA-256検証・画像前処理・各メディア間・保存トランザクションで確認されます。キャンセルを受けた保存処理はロールバックし、その後のAIタグを書き込みません。

2つのレベルは同じ検証済みWD ONNXモデルを1回実行します。詳細分析は別の外部AIへ
画像を送る機能ではなく、モデルが実際に返した候補を低めの判定基準で多く残すモードです。

モデル・ランタイムの詳細は
[`THIRD_PARTY_AI_NOTICES.txt`](../src-tauri/resources/THIRD_PARTY_AI_NOTICES.txt)
を参照してください。
