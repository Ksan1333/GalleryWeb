- アプリ版数: 0.2.0
- 更新日: 2026-09-04
- 対象: Windows 10 / 11 x64、React / TypeScript + Tauri / Rust
- 配布形式: NSISセットアップEXE
- DBスキーマ: 8（優先指定・閲覧履歴は既存のpreferencesに保存）

## 1. 全フォルダーと優先読み込み

「ギャラリー」と「お気に入り」の間に「全フォルダー」を配置する。Windowsのドライブ一覧から、空のフォルダーを含めて子フォルダーを辿れる。戻る、上へ、PC、パス入力、更新に対応する。アクセス権のない場所や切断されたドライブはエラーを表示し、権限を変更しない。

通常の閲覧では、選択したフォルダーの直下だけを走査する。画像・GIF・動画・PDF・ZIP/CBZを、既存の正方形コンパクトタイルと64件ページング・仮想スクロールで表示する。全ドライブを事前に再帰走査する方式ではない。全メディアギャラリーに並ぶのは読み込み済みのファイルであり、未閲覧・未優先の全PCファイルを先に索引化しない。

よく使う場所は「優先読み込みに追加」で指定する。優先フォルダーは配下も読み込み、複数の読み込み先がある場合は優先対象から処理する。既存の登録先は優先指定として自動的に引き継ぐ。設定と全フォルダー画面から優先指定を解除できる。解除しても元ファイル・カタログID・タグ・お気に入りを消さない。

カタログ内部のlibrary_rootsは索引の境界として残すが、閲覧の前提となる「登録」操作はなくす。新しい子フォルダーの索引境界を作る場合、既存メディアIDを新境界へ引き継ぐ。親の再帰走査は別境界の子を除外し、重複を作らない。

## 2. 更新と削除の反映

- OSファイル通知で優先フォルダー配下と、通常の閲覧済みフォルダー直下を監視する。監視設定が有効な場合に動作する。
- 通常のファイル作成・更新・削除は通知されたパスだけを照合し、ルート全件の走査を行わない。名前変更通知では旧・新パスを照合する。
- フォルダーの作成・削除は対象の範囲を照合する。通知欠落・エラー・起動・再接続では対象の再照合へフォールバックする。
- 監視設定と対象の変更は約2秒ごとに確認し、通知は最初の到着から約400ms後にまとめて処理する。通常は処理後約500msで一覧へ通知する。初回走査、大量コピー、遅いドライブでは時間が延びる。
- 全フォルダー画面はアプリへ戻った際にも現在の場所を再照合する。
- 上部、ギャラリー、フォルダーの更新操作はDBだけでなくディスク上の情報を照合する。部分的な走査失敗は読み取れた変更を反映し、全体更新では警告を表示する。
- 全体走査で見つからなかったファイルは、読み取り可能な親フォルダーの一覧を確認して個別に不存在を確定する。アクセスエラーが1件あっても、別の削除済みファイルの反映を全体停止しない。
- 1,000件以上の大量削除も反映する。ルート自体の切断・アクセス不能は大量削除と見なさず、既存カタログを保護する。
- 同じ親フォルダーの不存在確認は一覧を共有し、大量削除で同じディレクトリを繰り返し列挙しない。
- 復旧時は少数の存在サンプルだけを根拠に全削除フラグを戻さず、実際の走査結果を使用する。
- 元メディアのURLには更新時刻とサイズを付ける。ビュワー一覧はカタログ改訂番号が変わるとキャッシュを再構築する。

## 3. ビュワーの全画面

独立した「コントロールパネルを非表示」操作を削除する。Windows版はTauriのウィンドウ全画面APIを使用し、ウィンドウ枠とタスクバーを含む通常のウィンドウ表示から切り替える。ブラウザープレビューではDOM Fullscreen APIを使う。

全画面ではメニューを隠し、終了ボタンを残す。Escは先に全画面を解除し、ビュワーは閉じない。ビュワー終了時は開始前の全画面状態に戻す。連打は直列化し、失敗した操作の後にも再試行できる。動画の再生操作は従来どおり必要時に表示する。

## 4. 継続する機能

ギャラリーの任意の日・月・年グループ化、検索、タグ、年齢区分、お気に入り、OSごみ箱、ブックの右綴じ見開き、動画音量保存、AI分析、Xダウンロード、設定の移行を維持する。画像・動画・ブック別のギャラリーは読み込み済みメディアの絞り込みとして利用できる。

## 5. 検証と配布

配布物: `release/0.2.0/PixVault for Windows_0.2.0_x64-setup.exe`

検証対象:

1. TypeScript型検査、Vite本番ビルド、性能予算
2. レイアウト・ランタイム性能・テーマ契約
3. 全画面のネイティブ呼び出し、復帰、連打、例外、既存全画面保持のヘッドレステスト
4. Rust全テスト、実際のOSファイル通知による作成・更新・削除の反映
5. 1,010件中1,000件の削除、名前変更、削除された子フォルダー、ルート利用不能時の保護
6. 登録不要の浅い閲覧、空フォルダー、優先指定の解除とID・お気に入りの保持

PC画面操作は行わない。Windows実画面での見た目、全画面切り替えの目視、インストーラーのGUI実行は未確認。インストーラーは未署名で、SmartScreenが警告する場合がある。署名済み自動更新は従来どおり無効。

配布物とシンボルをプロジェクト直下のreleaseへ保管・照合後、対象を利用しているプロセスがなければ `cargo clean --manifest-path src-tauri/Cargo.toml` を実行する。node_modules、dist、ユーザーデータ、過去の仕様書・成果物は削除しない。
