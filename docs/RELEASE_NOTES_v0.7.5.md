# PixVault for Windows 0.7.5

## 修正内容

- 一部のH.264などの動画で、映像サイズが取得できているのにlibVLCの表示フレーム統計だけが0となり、PixVaultが読み込み中のままになる問題を修正しました。
- Direct3D11の再生状態と映像サイズを使って再生可能状態へ遷移するため、長時間動画やハードウェアデコード動画でも誤って再生失敗扱いになりにくくなります。

## 配布物

Windows 10/11 x64では`PixVault.for.Windows_0.7.5_x64-setup.exe`を使用してください。同梱VLCは変換用ではなく、PixVault内のネイティブ動画再生に使用します。

PC画面を使った目視確認はプロジェクト規則により実施していません。コード署名証明書がないため、WindowsインストーラーはAuthenticode未署名です。
