- アプリ版数: 0.2.1
- 更新日: 2026-09-04
- 対象: Windows 10 / 11 x64、React / TypeScript + Tauri / Rust
- 配布形式: NSISセットアップEXE
- DBスキーマ: 8（変更なし）

## 1. 全フォルダーの表示

ギャラリーとお気に入りの間の「全フォルダー」からWindowsドライブと子フォルダーを閲覧する。空フォルダーにも移動できる。事前登録は不要。通常は開いた場所の直下だけを読み込み、優先指定した場所は配下も先に読み込む。

ページに余白を設け、見出し、移動・パス入力・更新操作、優先先、一覧の順で配置する。一覧には残りのウィンドウ高さを割り当てる。大量のフォルダー・メディアは仮想スクロールを維持し、表示周辺だけを描画する。短いウィンドウで領域が不足した場合はページ側をスクロールでき、操作を画面外に切り捨てない。

パス入力欄は余白に合わせて伸縮するが「開く」は縮めず1行表示する。幅1200px以下ではパス入力を独立した行、680px以下では移動・パス・更新を縦に並べる。長い優先先名は省略表示し、優先先が多い場合は同じ行を横スクロールする。

高さ700px以下では英語の補助見出しと説明文を非表示にし、日本語のタイトルと全操作は残して一覧領域を優先する。

フォルダーは黄色のアイコンと名前を含む正方形コンパクトタイルにする。全フォルダーの名前は11px、最大2行。長い名前・フルパスはタイルのツールチップで確認できる。未集計の子フォルダーに0件バッジを表示しない。他のギャラリーの集計済み件数表示は維持する。

戻る、PC、上へ、パス入力、更新、優先指定・解除を維持する。アクセス権のない場所や切断されたドライブはエラーを表示し、権限を変更しない。

## 2. カタログとファイル同期

優先フォルダーは配下、通常の閲覧済みフォルダーは直下をOSファイル通知で監視する。監視設定が有効な場合、通常の作成・更新・削除は通知パスを照合し、全件走査しない。通知は最初の到着から約400msでまとめ、処理後に一覧へ通知する。通知欠落・起動・再接続では対象の再照合へフォールバックする。

更新操作はディスク上のファイルと照合する。不存在は読み取り可能な親フォルダーから確定し、ルートの切断やアクセス不能を大量削除と誤認しない。元メディアURLとビュワー一覧は更新情報でキャッシュを再検証する。

既存の登録先は優先指定として引き継ぐ。解除しても元ファイル、カタログID、タグ、お気に入りを削除しない。内部の索引境界と子フォルダーへのID引き継ぎを維持し、重複登録を防ぐ。未閲覧・未優先の全PCファイルを事前に索引化する方式ではない。

## 3. 継続機能

画像・GIF・動画・PDF・ZIP/CBZ、検索、タグ、年齢区分、お気に入り、OSごみ箱、任意の日・月・年グループ化を維持する。メディアは64件ページングで読み込み、大規模ライブラリを全件描画しない。

Windowsビュワーはネイティブウィンドウの全画面APIを使用する。Escで全画面を解除し、終了時は元の全画面状態へ復帰する。ブックの右綴じ見開き、動画音量保存、削除後の次メディア表示、AI分析、Xダウンロード、設定移行を維持する。

## 4. 検証と配布

- 配布物: `release/0.2.1/PixVault for Windows_0.2.1_x64-setup.exe`
- バージョン定義: package.json、package-lock.json、Cargo.toml、Cargo.lock、tauri.conf.jsonは0.2.1
- レイアウト回帰テスト: `node scripts/test-filesystem-layout.mjs`。Playwrightが通常解決できない環境では`PLAYWRIGHT_MODULE`でindex.mjsの絶対パスを指定する
- テストは実際のReactコンポーネントとCSSを隔離ページに読み込み、ネイティブAPIだけをメモリ内データに置き換える。実ドライブの走査・変更は行わない
- 2330×900、1440×900、1024×768、760×600、390×844、2330×520で、一覧高さ、文字、正方形、ボタン、はみ出し、長い優先先、240フォルダーの最終行、戻る、パス入力、空・エラー表示を検査する
- `--baseline-0.2.0`は旧版の対象コンポーネントとCSSをGitから読み、修正前の失敗を再現するためのオプション
- TypeScript、本番ビルド、既存の性能予算・レイアウト・ランタイム性能・20テーマ、全画面テスト、Rustテスト、NSISメタデータ・SHA-256を確認する

PC画面操作、画面撮影、可視GUI起動は行わない。Windows実画面での目視確認とインストーラーGUI実行は未確認。インストーラーは未署名でSmartScreenが警告する場合がある。署名済み自動更新は無効。

配布物・シンボル・チェックサムをrelease配下にコピーして照合後、使用中プロセスがない場合にcargo cleanを実行する。node_modules、dist、ユーザーデータ、過去版の成果物・仕様書は保持する。
