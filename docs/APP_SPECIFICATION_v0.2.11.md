# PixVault for Windows アプリ仕様書 v0.2.11

更新日: 2026-09-10。対象: Windows 10/11 x64。DBスキーマ9（変更なし）。本書以外はAPP_SPECIFICATION_v0.2.10.mdを継承する。

## 動画再生

通常は元のローカル動画をWebView2で再生する。メディアエラーまたは初期15秒間に最初の映像データが届かない場合、互換再生ジョブを開始する。メタデータのみ・autoplay待ちを実際の映像到着と混同しない。開始後の通常のバッファリングでは再変換せず、小さな状況表示のみを出す。音声のみ等の場合には「互換再生」ボタンで切り替えられる。

H.264 8bit 4:2:0映像は再圧縮せず、音声をAACステレオに変換してfaststart MP4に再格納する。それ以外はVP9/Opus WebMへ変換する。再格納した動画もWebView2で失敗する場合は再圧縮を1回試す。失敗は再試行ボタンと理由を表示し、無限再試行はしない。解像度・時間軸は元動画を基準とし、字幕と追加音声トラックは互換再生では対象外。

FFmpeg LGPL shared build n8.1.2-50-g1a748fe2cd（BtbN 2026-08-31）を初回に直接HTTPSダウンロードする。70,835,150 bytes、SHA-256 `e9712ffbdb03ef71bbab660c75b835bfe698ef6fad0247c76d8d394a39a3db63`に固定し、全体検証後のみ実行。配布元とライセンスは同梱THIRD_PARTY_NOTICESに記載し、取得物内の文書も保存する。保存先はアプリローカルデータ下のvideo-engine/ハッシュ。ネットへの動画アップロードはない。

ジョブはバックグラウンドで実行し、IPCの待機や取得状態によってビュワーをロックしない。変換中も閉じる・次への移動を許可し、遅れて到着したジョブIDも中止する。Windowsの非表示・低い優先度の子プロセスとして実行し、親プロセス終了時はJob Objectによって子プロセスを終了する。

## 保存容量とライフサイクル

元動画を上書きしない。互換再生用ファイルはアプリデータ/video-playback/UUID内へ作り、再生セッションが閉じられたら削除する。切り替え時はジョブを中止し、未完成ファイルも削除する。異常終了の残存ジョブは次回起動時に整理する。1ジョブの出力上限2GiB、変換上限30分、エンコード2スレッド。エンジンは次回に備えて保持する。

動画要素とWeb Audio解析は同じ動画セッションに紐付ける。別メディアに移ると旧解析を破棄し、新しい要素で解析を始める。互換形式に切り替えるときは同一要素のsourceを変更し、解析と要素の不一致を防ぐ。カタログから時間情報が追加されても再生位置・読み込み状態を初期化しない。

## 読み込み表示

動画は画面端の状況表示と再試行ボタン、画像・ブックは小さな読み込みバッジとする。全領域の背景・オーバーレイは描画しない。表示部分はpointer-events:none、再試行ボタンのみ操作を受け付け、再生面・次へ・閉じる操作を遮らない。

## 検証と制約

TypeScript型検査、テーマ20種・レイアウト・ブック操作の回帰検査、ヘッドレスReactの再生状態・フォールバック・中止・再試行テストを実施。Rust通常テスト176件とWindowsパステスト1件が成功（外部入力等を要する5件は通常実行では除外）。

実エンジン試験は別途明示実行し、合成MPEG-4/AVI、FFV1/MKV、WMV2/WMV、H.264＋PCM/MOV、HEVC＋PCM/MKVの5種類を変換。出力をFFmpegと隔離ヘッドレスChromiumで実際にデコードし、映像フレーム・解像度・長さを確認した。元ファイルの不変、faststart配置、強制再圧縮、変換プロセス中止も検証。

再現コマンド: `PIXVAULT_TEST_ENGINE_DATA`を`artifacts/video-playback-tests`の絶対パスに設定し、`cargo test --manifest-path src-tauri/Cargo.toml --release video_playback -- --include-ignored`、続けて`node scripts/test-video-codecs.mjs`を実行する。検証後、この合成データと取得した検証用エンジンは削除可能。

実機画面操作は禁止されているためWindows WebView2実機とインストーラーのGUI操作は未確認とする。実ユーザーの動画はテストに使用していない。

初回の互換再生はインターネット接続が必要。再圧縮は全体の処理後に再生開始するため、長い動画は時間がかかる。非対応形式・破損・DRM・容量超過等はエラー表示となる。エンジン取得元が利用不能の場合は明示的な再試行案内を出す。
