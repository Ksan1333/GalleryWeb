# PixVault for Windows アプリ仕様書 v0.5.0

更新日: 2026-09-13。対象: Windows 10/11 x64、DBスキーマ9。以下以外はv0.4.1の仕様を継承する。過去版の成果物・仕様書は残す。

## 統合ギャラリー

- サイドバーの画像・動画・ブック個別画面を廃止し、画像、GIF、動画、ZIP／CBZ／PDFブックを「ギャラリー」で扱う。
- ギャラリーの空き領域またはアイテムの右クリックメニューから、画像・GIF・動画・ブックをチェックボックスで表示／非表示にできる。少なくとも1形式は常に有効とする。
- 表示形式は特大アイコン、大アイコン、中アイコン、小アイコン、一覧、詳細から選択する。アイコン表示ではサムネイルと文字領域を含む正方形タイルを維持する。
- 並び順とグループ化は右クリックメニューへ残す。グループ化は「なし／更新日／更新月／更新年」に対応し、ギャラリー上部のグループ化セレクターは表示しない。
- 「全フォルダー」はギャラリーとお気に入りの間に置き、ファイルシステムを必要な場所だけ読み込む。

## ビュワーパネル

- メディアを開いた直後は、一覧および「情報・レコメンド」を閉じた状態にする。
- 一覧と「情報・レコメンド」は独立して上、下、左、右、フローティングへ配置できる。配置はボタン操作またはドラッグ終点から選び、設定を保存する。
- フローティング配置はドラッグ位置を維持する。閉じたパネルは48pxの丸いアイコンになり、再度開ける。
- 上下左右へ開いたパネルの領域はメディア表示領域から確保し、動画操作やページ操作を覆わない。同じ辺へ2パネルを配置した場合は必要な合計領域を確保する。
- Escape／戻る操作は、開いている一覧または情報パネルを先に閉じ、その後の操作でビュワーを閉じる。

## Explorer連携と並び順

- Windows Explorerから関連付けファイルを直接開いた場合、対象ファイルを最優先で表示し、背後では親フォルダーの「全フォルダー」画面を開く。
- ビュワーを閉じても親フォルダー画面を破棄せず、そのフォルダーの一覧へ戻る。
- Explorer経由のフォルダー一覧とビュワー移動は、ともにファイル名の昇順を使用する。
- ファイル名は大文字小文字を区別しない自然順で比較し、数字の連続部分は数値として扱う。例: `1.webp, 2.webp, 10.webp`。同値時は相対パスとIDで決定的に並べる。

## 互換性

- 旧`viewerInfoLayout`値の`sidebar`は右、`bottomSheet`は下として読み替える。
- 既存のギャラリー密度設定は新しい表示形式へ読み替え、以後の変更は表示形式とタイル寸法を同時に保存する。
- libVLCによる元動画の直接再生、自動音量減衰、変換機能を持たない構成、削除後の次メディア表示はv0.4.1から継続する。

## 検証

- TypeScript型検査、Vite本番ビルド、レイアウト契約、ギャラリー設定、外部ファイル起動、Explorer遷移、ビュワー操作、ライトテーマのコントラストを検証する。
- Rust通常試験で、全カタログ機能およびSQLite自然順照合を検証する。
- Windows NSISインストーラーの版数、製品版数、サイズ、SHA-256、署名状態、関連付けをCLIで確認する。
- 初期JS／gzip、初期CSS／gzip、最大アプリ／workerチャンクの従来上限は据え置く。遅延チャンクを含む全アセット上限のみ、新しいパネルとギャラリー操作分10 KiBを追加して2,646 KiBとする。

## 未確認事項

プロジェクト運用規則に従いPC画面を操作しない。ヘッドレスChromiumとCLIで寸法、操作、コントラストを確認するが、実画面での見た目、ドラッグ感覚、Windows Explorerの全言語・記号に対する厳密な並びの一致、インストーラーGUIは未確認。配布物は署名なしの検証版とする。

## 確認結果

- TypeScript型検査、Vite本番ビルド、20テーマ、6画面幅のファイルシステム配置、ギャラリー契約、外部起動、Explorer遷移、ビュワー操作、ブック、設定、22万件の合成カタログを使った起動／スクロール性能試験が成功。
- Rust通常試験は186件、Windowsパス統合試験は1件成功。外部AI、公開X、専用libVLC合成fixtureが必要な9件は通常実行では省略。
- 最終性能値は初期JS 317.6 KiB／gzip 99.3 KiB、初期CSS 117.1 KiB／gzip 22.4 KiB、全アセット2,645.0 KiB。初期表示の従来上限は変更していない。
- NSISに含まれる画像、GIF、動画、ZIP／CBZ、PDFの関連付け登録／削除を検証。599個の入力ファイルを配布用ディレクトリーへコピーし、コピー前後のSHA-256一致を確認。チェックサム2ファイルを含む最終601ファイルを保存。
