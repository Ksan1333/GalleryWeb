# PixVault for Windows 0.7.1

ビュワーを開いたときにメディアを広く見られるよう、一覧・レコメンドの入口を下部ツールバーへまとめました。

## 変更内容

- 初期は一覧・レコメンドを閉じ、右端と下端の大きな空のバーを解消。
- 下部の「一覧」「レコメンド」ボタンから開閉。標準では一覧は下、レコメンドは右へ展開。
- 変更済みの配置を維持。開いたパネルのドラッグ移動、フローティング最小アイコン、一覧の取得済みデータ保持も継続。
- 狭いウィンドウでもパネルボタンを固定表示。閉じた後は対応するボタンへキーボードフォーカスを戻す。

## 確認内容

TypeScriptと本番ビルド、760／1024／1440px幅でのパネル・動画・ブックの配置、20テーマの文字コントラスト、キーボード／タッチ、配置保存、一覧保持、外部ファイルの先行表示、ネイティブ動画ブリッジ、ブックと設定の回帰試験を確認しました。初期読込と全アセット容量は従来の上限内です。

ギャラリー整合性／優先フォルダーの22件も合格。今回の変更はフロントエンドと検証コードで、Rustバックエンドの動作コードに変更はありません。

## 既知の制限

PC画面を操作しないプロジェクト規則により、実画面の操作感とインストーラーGUIは未確認です。コード署名証明書がないためインストーラーはAuthenticode未署名です。

Windows 10/11 x64では添付の`PixVault.for.Windows_0.7.1_x64-setup.exe`を実行してください。`vlc-3.0.23.tar.xz`は同梱libVLCの対応ソースで、通常のインストールには不要です。
