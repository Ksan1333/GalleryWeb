# PixVault for Windows 0.2.6 — 画像先行表示の検証版

2026-09-05 / Windows x64 / DBスキーマ9

## 変更内容

- 外部ファイル起動では画像の表示を最優先にし、親フォルダー走査・一覧・件数・位置確認を後回しにする。
- 起動直後のホームと集計、おすすめ・サムネイル列・タグ辞書も初回の画像表示後へ延期する。
- 開いている画像を作り直さず、同じビュワーへ親フォルダーの全件ページングを接続する。
- 同じ画像への連続した外部要求、ロード途中の終了、遅い位置照会と古い応答を処理する。
- 起動引数の解析前に初回キューが空と判定される競合を防ぎ、確認待ちはblocking workerへ分離する。
- Windowsの短い別名パスと正規パスの照合を補正し、削除済みパスは残存する祖先から安全に照合する。

詳細: `CHANGELOG.md`、`docs/APP_SPECIFICATION_v0.2.6.md`。仕様書・成果物の過去版は保持する。
