# PixVault for Windows 0.7.3

動画を元の縦横比のまま表示し、ブックのページ送りとメディア移動のキー操作を分離しました。

## 変更内容

- 横長・縦長のビュワーステージでも元動画のアスペクト比を維持し、上下左右を切らずに中央配置。
- 左右端へホバーすると、移動可能な「前のメディア」「次のメディア」を薄い案内で表示。
- 左右端の短いタップによる前後移動は継続。
- ブックの通常左右キーはページ送り、`Ctrl＋左右キー`は前後の本へ移動。
- 動画中央の単タップ再生／停止、左右ダブルタップシークは維持。

## 確認内容

指定動画は内容を開かずメタデータのみを確認し、1280×720・29.97fpsの16:9動画であることを確認しました。ヘッドレスChromiumで、16:9動画を横長ステージへcontain配置する矩形、libVLCのオーバーレイ切抜き、左右端ホバー案内、端タップと左右キー、動画操作との非干渉、ブックのページ送り／本移動を確認しています。

## 既知の制限

PC画面を操作しないプロジェクト規則により、指定動画を実アプリで再生した目視確認とインストーラーGUIは未確認です。コード署名証明書がないためインストーラーはAuthenticode未署名です。

Windows 10/11 x64では添付の`PixVault.for.Windows_0.7.3_x64-setup.exe`を実行してください。`vlc-3.0.23.tar.xz`は同梱libVLCの対応ソースで、通常のインストールには不要です。
