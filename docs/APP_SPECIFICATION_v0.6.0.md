# PixVault for Windows アプリ仕様書 v0.6.0

更新日: 2026-09-13。対象: Windows 10/11 x64、DBスキーマ9。以下以外はv0.5.0の仕様を継承する。過去版の成果物・仕様書は残す。

## ギャラリー表示

- アイコン表示、一覧、詳細の全表示形式で、お気に入りとWindowsのごみ箱へ移動する操作を利用できる。一覧と詳細では両ボタンを常時表示する。
- メディア種類の文字ラベルは表示しない。サムネイル右上に、画像は青、GIFは紫、動画は赤、ブックは黄、文書は緑のアイコンを表示する。
- 年齢区分が未設定のカードに「未選択」を表示しない。ZIP／CBZカードに`ARCHIVE`を表示しない。ページ数など実値を持つ補足情報は維持する。
- 選択中カードは青い外枠と、サムネイル上の青い半透明カバーで示す。

## ビュワーの枠と画像表示

- 画像の表示倍率、拡大、縮小、等倍、画像全体表示は、ファイル名を表示するヘッダー内のツールバーに置く。画像上へ独立した倍率パネルを重ねない。
- 全画面ボタンの隣に「すべての枠を非表示」を置く。実行時はヘッダー、一覧、情報・レコメンド、ブック操作、下部操作を隠し、右上の復元ボタンまたはEscapeで戻す。
- ネイティブ全画面中は「すべての枠を非表示」を表示しない。全画面解除時は開始前の物理座標、物理サイズ、最大化状態を復元する。

## 一覧・情報パネル

- 一覧と情報・レコメンドは同じドラッグ判定および移動先表現を使う。ドラッグ中は対象辺または中央へ青い半透明の点線枠と「○ …へ移動」を表示する。
- フローティング配置で最小化した丸いアイコンは、そのアイコン自体をドラッグして自由に移動できる。クリックは開閉、4pxを超える移動はドラッグとして扱い、移動直後の誤開閉を抑止する。
- 上、下、左、右へ配置した最小パネルは丸いアイコンにせず、辺に沿う長方形タブとして表示する。タブのドラッグハンドルから別の場所へ移動できる。
- Explorerから直接開いたファイルでは、カタログ上の現在位置を取得した後に一覧をその項目へ中央寄せし、ビュワー移動のたびに追従する。横配置の一覧はスクロールバー用余白を確保し、ファイル名を隠さない。

## 親フォルダータグ

- 動画、PDF、ZIP／CBZブックは、スキャン時点の親フォルダー表示名を`source=folder`の管理タグとして1件持つ。ルート直下ではライブラリールートの表示名を使う。
- AフォルダーからBフォルダーへ移動またはフォルダー名を変更した場合、同一メディアIDの旧管理タグ関係を削除してBのタグ関係を作成する。お気に入り、利用者タグ、AIタグ、しおりは維持する。
- 画像とGIFには親フォルダータグを自動付与しない。既存メディアは次回の対象フォルダースキャンまたはファイル監視による再照合で反映する。

## Windows Explorer準拠の名前順

- WindowsではShellの`StrCmpLogicalW`をSQLiteの`PIXVAULT_NATURAL`照合へ登録し、名前順のカタログ、Explorerフォルダー、アーカイブページ、サムネイル候補に使用する。
- 数値部分は数値として扱い、記号、数値、英字の比較もExplorerへ委譲する。代表例は`[a]`, `1`, `2`, `10`, `a`。
- Explorerから直接開くフォルダー画面とビュワー一覧は名前昇順を固定し、同じSQLite照合とページインデックスを共有する。
- Windows以外のビルドでは従来の大文字小文字を区別しない自然順をフォールバックとして使う。

## 検証

- TypeScript型検査、Vite本番ビルド、レイアウト契約、ライト／ダークテーマ、外部ファイル起動、Explorer遷移、ビュワー操作をヘッドレスで検証する。
- Rust試験で、`StrCmpLogicalW`の`[a]`, `1`, `a`および数値順、動画／ブックのフォルダー移動後に管理タグが1件だけ残ることを検証する。
- Windows NSISインストーラーは版数入りで作成し、ファイル関連付け、同梱libVLC、SHA-256、Authenticode状態をCLIで確認する。
- 初期JavaScript／gzip、初期CSS／gzip、最大アプリ／workerチャンクの上限は据え置く。遅延読み込みのビュワー操作と更新履歴を含む全アセット上限だけを2,654 KiBとする。

## 未確認事項

プロジェクト運用規則に従いPC画面を操作しない。実画面でのドラッグ感覚、Windowsウィンドウの視覚的な復元、インストーラーGUIは未確認とし、ヘッドレスChromium、Rust試験、生成物検査で代替する。配布物はコード署名証明書を持たないため署名なしの検証版とする。

## リリース検証結果

- TypeScript型検査、Vite本番ビルド、テーマ、レイアウト、6画面幅のファイルシステム表示、22万件相当の起動・スクロール、サムネイル調停、外部ファイル起動、Explorer遷移、ビュワー、設定、PDF／ブック、libVLC再生ブリッジの自動試験に合格した。
- Rustは187件合格、Windows統合試験1件合格、失敗0件。AIモデル、X連携、検証用VLCサンプルを必要とする9件は環境依存試験として除外した。
- 性能予算は初期JavaScript 317.7 KiB、gzip 99.3 KiB、CSS 117.9 KiB、gzip 22.5 KiB、最大アプリチャンク423.8 KiB、worker 1,232.8 KiB、全アセット2,650.9 KiBで合格した。
- NSISインストーラーは56,546,167 bytes。SHA-256は`D0D73BAD6BFB934882B428E7E4793236F574A0783121FF210CD9DC8B0A768B6F`、Authenticode状態は`NotSigned`。13種類のファイル関連付けとアンインストール時の解除を生成済みNSISから検証した。
