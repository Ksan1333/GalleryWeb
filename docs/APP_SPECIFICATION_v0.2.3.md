## 1. ギャラリーの表示範囲

サイドバーの「ギャラリー」は、優先フォルダーとその配下の読み込み済みメディアだけを表示する。優先でない場所を「全フォルダー」で開いて索引に読み込んでも、それだけではギャラリーには追加しない。優先フォルダーがない場合は空の状態を表示し、優先指定を案内する。画像・GIFは通常の対象とし、動画・ブックは従来の表示設定に従う。検索、タグ、年齢区分、日付、フォルダーによる絞り込みは優先範囲との積集合になる。

優先フォルダーの子孫に、以前から独立したカタログIDを持つ子フォルダーがあっても対象に含む。Windowsのドライブ・UNC・拡張パス表記・大文字小文字を正規化し、区切り境界を確認する。たとえば優先先がPicturesなら、その配下のPictures/Childは含むが、Pictures-otherは含まない。無効な親フォルダーから優先を継承しない。

内部MediaQueryに省略可能なpriorityOnly条件を追加する。省略時はfalseで、従来の問い合わせ範囲を保つ。ギャラリーだけがtrueを指定し、一覧、件数、日付グループ、ビュワーの全件一覧・次ページ取得、Ctrl・Shift範囲選択まで引き継ぐ。表示後に非優先項目を間引く方式ではなく、DBの取得条件で絞るのでページ件数と位置を一致させる。

優先判定はメディアごとの相関検索ではなく、有効なフォルダーカタログの集合で行う。対象root IDを単一のJSONパラメーターと非相関のjson_each IN条件へ渡し、多数のフォルダーでもSQLiteのバインド変数上限に達しないようにする。0候補時には明示的に0件を返す。

## 2. 優先設定の変更とデータ保持

優先指定を外したフォルダーは、別の優先先の配下でない限りギャラリーから除外する。元メディア・DBのメディアID・タグ・お気に入りを削除する操作ではない。再び優先指定すれば、既存の索引を利用して表示対象に戻る。旧登録先で優先設定が未記録の場合は、既存仕様どおり優先扱いとして引き継ぐ。

優先の追加・解除に成功した時点でカタログ更新を通知する。追加後のスキャンが失敗しても、成功済みの優先指定は表示条件へ反映する。設定変更の失敗は成功通知として扱わない。

優先条件の有無は一覧・件数キャッシュのキーに含め、通常問い合わせと混同しない。問い合わせ開始時のカタログ世代を保持し、優先変更や再読み込みで世代が変わった後に到着した古い結果を、キャッシュへ保存し直さない。

## 3. 変更しない画面・機能

「全フォルダー」は登録なしでドライブ・子フォルダーを閲覧できる。通常は開いた場所の直下、優先先は配下も読み込み対象とする。非優先でも全フォルダーの中では引き続きメディアを開ける。

「お気に入り」、ホームのお気に入り棚、画像・動画・ブックの種類別フォルダー画面には、この優先限定条件を強制しない。非優先の星付きメディアもお気に入りから閲覧できる。ホームの全体件数はカタログ全体の集計であり、優先限定されたギャラリー件数とは異なる場合がある。

正方形のコンパクトタイル、64件ページング、仮想スクロール、全画面、ブックの右綴じ、動画音量保存、削除後の次メディア表示、ファイル自動同期、AI分析、Xダウンロード、設定移行を維持する。

## 4. 性能・レイアウトの継続仕様

0.2.2の軽量化を維持する。ホームのお気に入りは全体集計を待たず、任意UIは最低750ms遅延する。DB集計・一覧取得・サムネイル索引読み込みは画面の同期処理から分離する。

ホーム棚のサムネイルは画面内に入った項目から要求する。通知は描画フレーム単位に集約し、キャッシュ整理はまとめて行う。画面外の未生成サムネイルで原寸画像・動画・PDF・ZIPの重い表示処理を開始しない。解像度・画質は変更しない。追加ページ到着時に既存カードを不要に再描画しない。

全フォルダー画面は残りウィンドウ高さを一覧へ割り当て、タイルは名前込み正方形、名前は11px・最大2行とする。狭い画面では操作を折り返し、短い画面でも切り捨てない。

ファイル監視の購読は即開始し、通常変更は約400msでまとめて差分照合する。起動・再接続の全体照合だけ8秒の猶予と最後の前面操作・要求通知から2秒の空きを待つ。30秒経過後は開始対象にできるが、全ルートの開始・完了期限ではない。巨大ルートの全体照合は開始後に細分化・中断しないため、ディスク競合が残る可能性がある。

ブックのページキャッシュを含むユーザーデータの保存・削除仕様は変更しない。この版のビルドクリーンで元メディア・サムネイル・ページキャッシュ・DBを削除しない。
