# PixVault for Windows 0.6.0

ギャラリー表示、ビュワーのパネル操作、Explorer準拠の名前順と親フォルダータグを改善したリリースです。

## 主な変更

- 一覧・詳細表示でもお気に入り／ごみ箱操作を常時表示し、選択状態を青い半透明カバーへ統一
- `未選択`と`ARCHIVE`の文字ラベルを廃止し、メディア種類を色付きアイコンで表示
- 情報・レコメンドとメディア一覧のドラッグUIを統一し、フローティング最小アイコンを移動可能化
- 画像倍率操作をファイル名ヘッダーへ移し、画像全体表示とすべての枠を隠す操作を追加
- 全画面解除時のウィンドウ位置・サイズ・最大化状態を復元
- 直接開いたファイルへ一覧を追従させ、横スクロールバーとファイル名の重なりを修正
- 動画とブックへ現在の親フォルダーだけを管理タグとして同期
- Windows Explorerの`StrCmpLogicalW`を名前順へ採用
- パッケージスクリプト内でも署名・SHA-256検査が安定して動くようリリース検証を改善

## 検証

TypeScript、Vite本番ビルド、ヘッドレスUI／性能／外部ファイル起動／libVLC試験、Rust 187件とWindows統合試験1件、生成NSISのファイル関連付け、SHA-256を検証済みです。PC画面を操作しない運用規則のため、インストーラーGUIと実画面のドラッグ感覚は未確認です。

インストーラーはコード署名証明書を持たないため、Authenticode未署名です。
