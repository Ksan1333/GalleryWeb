# PixVault for Windows アプリ仕様書 v0.7.4

更新日: 2026-09-14。対象: Windows 10/11 x64。以下以外はv0.7.3の仕様を継承する。過去版の成果物・仕様書は保持する。

## 動画の表示比率

- libVLCのネイティブ動画出力を初期化するとき、スケールを自動調整（0）へ戻し、手動のアスペクト比上書きを解除する。
- 透明canvasではなく動画ステージへネイティブ矩形を配置し、カタログまたはlibVLCから得た実寸の比率でcontain相当に中央配置する。
- 再生開始後にlibVLCの実寸が通知されたときは、DOMのデータ属性とネイティブ表示領域を直ちに更新する。初期測定が実寸未取得の暫定値でも、比率が確定した後に引き伸ばしが残らない。
- ステージ外の領域、操作バー、モーダル、一覧、レコメンドは引き続きネイティブ矩形から切り抜く。動画ファイル自体は変換・置換しない。

## 確認方法と未確認事項

ヘッドレスChromiumで16:9動画を横長ステージへcontain配置し、canvasの固有比率を使わないこと、実寸属性変更後に再計算されること、オーバーレイ切抜きと既存の左右端移動操作を確認する。libVLC APIのスケール・アスペクト比リセット呼び出しはRustビルドで確認する。

PC画面操作禁止の規則に従い、指定動画を実アプリで表示した目視確認とインストーラーGUIは未確認。コード署名証明書がないため、WindowsインストーラーはAuthenticode未署名。
