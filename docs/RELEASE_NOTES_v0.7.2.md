# PixVault for Windows 0.7.2

一部の動画で上部が見切れる表示を修正し、ビュワーの端とキーボードから前後のメディアへ移動できるようにしました。

## 変更内容

- libVLCの描画領域を透明canvasの一時的な寸法ではなく、実際の動画ステージ全体へ固定。
- 表示領域の左端を短くタップすると前、右端を短くタップすると次のメディアへ移動。
- 左キーで前、右キーで次へ移動。画像、GIF、動画、ブックで操作を統一。
- 端タップでは動画の再生／停止を同時実行せず、中央単タップと左右ダブルタップの既存操作を維持。
- ブックのページ送りは画面ボタン、PageUp／PageDown、Home／Endおよびシークバーで引き続き操作可能。

## 確認内容

指定動画は内容を開かずメタデータのみを確認し、1280×720・29.97fpsの通常の16:9動画であることを確認しました。合成データによるヘッドレス試験で、canvasが小さくずれていても動画ステージ全体の矩形を使うこと、左右端タップと左右キーの移動、動画の再生・シークとの非干渉を確認しています。

## 既知の制限

PC画面を操作しないプロジェクト規則により、指定動画を実アプリで再生した目視確認とインストーラーGUIは未確認です。コード署名証明書がないためインストーラーはAuthenticode未署名です。

Windows 10/11 x64では添付の`PixVault.for.Windows_0.7.2_x64-setup.exe`を実行してください。`vlc-3.0.23.tar.xz`は同梱libVLCの対応ソースで、通常のインストールには不要です。
