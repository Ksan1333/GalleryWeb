# PixVault for Windows 0.7.4

動画ビュワーで、元動画の比率を保つネイティブ表示をさらに安定させました。

## 変更内容

- libVLCのスケールを自動調整へ戻し、アスペクト比の手動上書きを解除して、横長ステージで上下が切れないよう追加修正。
- libVLCから動画の実寸が通知された直後に表示矩形を再計算し、再生開始直後の一時的な引き伸ばしが残らないよう修正。
- v0.7.3で追加した左右端の前後移動、ホバー案内、ブックのキー操作分離は継続。

## 確認内容

指定動画は内容を開かずメタデータのみ扱います。ヘッドレスChromiumのネイティブ描画契約テスト、TypeScript型チェック、Rustチェックを実行し、16:9のcontain配置と実寸更新経路を確認します。

PC画面操作禁止の規則により、実アプリでの目視確認とインストーラーGUIは未確認です。コード署名証明書がないためインストーラーはAuthenticode未署名です。

Windows 10/11 x64では`PixVault.for.Windows_0.7.4_x64-setup.exe`を使用してください。
