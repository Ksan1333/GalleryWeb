# v0.8.0 — 2026-10-16

## 変更内容

- Windows Media Foundationによる元動画の直接再生を追加しました。WebViewの読み込み・シーク失敗時にWindows標準エンジンを試し、非対応の場合はVLCへ切り替えます。
- 「Windows標準で再生」「VLCで再生」から現在位置を引き継いで切り替えられます。
- 総時間不明時にシークバーが右端へ張り付く問題を修正しました。

## 確認内容

- ヘッドレスでエンジン切り替え、マウス・タッチ・キーボード操作、パネル配置を確認。
- Windows CIでRustの193テスト成功（環境依存の既存9テストは保留）。Media Foundationの合成動画読み込み、フレーム取得、シーク、一時停止、ファイル解放をヘッドレスで確認。
- インストーラー検証結果とSHA-256はGitHub Releaseに記載します。

## 既知の制約

- Windows標準経路はOSの対応コーデックに依存します。起動速度の改善と全形式のシークを保証するものではありません。
- Windows標準経路のフレーム保存、シーク画像プレビュー、自動音量補正は未対応です。必要な場合はVLCへ切り替えてください。
- 実WebView2の映像、DPI、音声同期、およびユーザーの問題動画による確認は未実施です。
