# PixVault for Windows アプリ仕様書 v0.7.1

更新日: 2026-09-13。対象: Windows 10/11 x64。以下以外はv0.7.0の仕様を継承する。過去版の成果物・仕様書は保持する。

## ビュワーの初期配置

- 初期は一覧と情報・レコメンドを閉じる。右端／下端の大きな空のバーは表示せず、閉じたドックパネルの予約幅・高さは0とする。
- 下部ツールバーの左側へ「一覧」「レコメンド」の入口をまとめる。アイコンに日本語ラベルを添え、開いているボタンは強調する。ボタンは最低38pxの高さを持つ。
- 初期展開位置は一覧が下、情報・レコメンドが右。すでに保存された上・下・左・右・フローティングの配置は維持し、移行時にリセットしない。
- 開いたパネルはメディアと重ならない領域に表示し、パネル内の配置ボタンとドラッグで移動できる。
- 閉じたドックパネルはDOM／Reactの状態を維持したまま非表示にし、一覧の取得済みページを破棄しない。フローティングを最小化した場合は移動可能な丸いアイコンを維持する。
- 1280px以下の幅では下部をパネルボタンとメディア操作の2列にし、メディア操作のみ必要に応じて横スクロールする。パネルボタンはスクロールで隠れない。
- ボタンは`aria-expanded`と`aria-controls`で状態と対象を示す。Escapeまたはパネル内の閉じる操作後は対応する下部ボタンへフォーカスを戻す。
- 全画面／すべての枠を非表示では、従来どおり下部ツールバーも隠す。外部ファイル起動では最初の画像等の表示を優先し、周辺UIが準備できるまでパネルボタンを無効にする。

## 確認方法と未確認事項

CLIと合成データを使ったヘッドレスChromiumで、初期配置、開閉、狭いウィンドウ、保存済み配置、キーボード、タッチ、一覧保持を確認する。動画描画・ファイル操作のバックエンドはv0.7.0から変更しない。

PC画面操作禁止の規則に従い、実画面での操作感とインストーラーGUIは未確認。コード署名証明書がないため、WindowsインストーラーはAuthenticode未署名。

## 検証結果

- ヘッドレスの実コンポーネント試験で、760×600、1024×768、1440×900の初期余白ゼロ、ボタンの可視性、動画・ブック操作群との非重複、パネル展開時の表示領域を確認した。
- パネル開閉時のDOM保持、キーボードEnter／Escape、タッチ、閉じた後のフォーカス回復、保存済みleft／top配置、フローティングの48px丸アイコンを確認した。
- 新しいボタンは開／閉の両状態で20テーマのコントラスト4.5:1以上を確認した。既存の動画入力、一覧保持、RTLブック送りも合格。
- 外部ファイル起動と画像先行表示、ネイティブ動画描画ブリッジ、ブック8件、設定10件、レイアウト／実行時性能契約、テーマ試験に合格。
- ギャラリー整合性／優先フォルダーの22件に合格。外部起動のVM試験を現行のキャッシュ保持状態へ合わせ、既知ページ、退避された現在位置、別検索条件、既知から未知ファイルへの切替、SQL失敗の検証を追加した。
- TypeScriptと本番フロントエンドビルドに合格。初期JavaScriptは317.8 KiB（gzip 99.3 KiB）、初期CSSは118.0 KiB（gzip 22.5 KiB）、全アセット2,661.6 KiB。すべて既存の容量上限内で、上限を変更していない。
- Windowsリリースビルド、生成済みNSISの関連付け4試験、版数とEXEメタデータ検査に合格。配布用599ファイルを`release/0.7.1`へコピーし、コピー元・先のSHA-256一致を確認した。
