# PixVault for Windows アプリ仕様書 v0.7.10

## 動画再生

- 元ファイルのMIMEをWebViewの`canPlayType`で確認し、対応可能な動画はHTML videoで直接再生する。
- 非対応のMIMEはWindows同梱libVLCで直接開く。対応可能と判定されても、デコードエラーまたは再生可能になる前の8秒間の停滞でlibVLCへ切り替える。
- WebViewで再生可能になった動画は初期待機タイマーの対象外とし、再生中の一時的なバッファリングでは切り替えない。
- 動画切替時は前のイベント監視とVLCセッションを解放する。失敗したVLCは明示的に再試行できる。
- どちらの経路も元動画を変換・置換せず、再生用一時動画やFFmpegの取得は行わない。
- Linuxとブラウザプレビューは従来どおりWebView/ブラウザのデコーダーを利用する。
- VLCの表示・DPI・操作・キャプチャはv0.7.9の実装を維持する。

## Windowsセットアップ

- Microsoft Visual C++ x64 14.51.36247.0を同梱する。ビルド時・実行直前に固定SHA-256とMicrosoft Authenticode署名を確認する。
- 64ビットSystem32内のmsvcp140.dll、msvcp140_1.dll、vcruntime140.dll、vcruntime140_1.dllの存在と版数を確認し、必要条件を満たす場合は導入を省略する。
- 不足時はMicrosoftのセットアップを`/install /quiet /norestart`で実行する。必要なUAC確認はユーザーが承認する。自動再起動はしない。
- 0または1638の終了後にもDLLを再確認する。失敗・キャンセル時はアプリのセットアップを中止する。
- 3010の場合は再起動が必要な旨を案内して終了する。再起動後にセットアップを再実行する。
- ランタイムは共有コンポーネントであり、アプリのアンインストール時に削除しない。

## 検証と制約

- `test:video-selection`: WebView直接再生、失敗時切替、非対応MIME、初期停滞、古いイベントの無視、VLC再試行をヘッドレス検証する。
- `test:vcredist`: 導入省略、成功、新版導入済み、再起動要求、キャンセル、ハッシュ・署名不正、導入後DLL不足をモック検証する。
- `test:video-playback`と`test:viewer-interactions`で既存の操作を検証する。
- 実動画・実WebView2での再生開始時間、ランタイム未導入PCでのUACとインストーラー実行は別途確認が必要。画面操作は行わない。
