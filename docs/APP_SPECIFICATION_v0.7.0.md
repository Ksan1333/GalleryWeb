# PixVault for Windows アプリ仕様書 v0.7.0

更新日: 2026-09-13。対象: Windows 10/11 x64。以下以外はv0.6.0の仕様を継承する。過去版の成果物・仕様書は保持する。

## ギャラリーとプロパティ

- 画像・GIF・動画・ブック・文書の色付き種類アイコンはサムネイル左上に表示する。年齢区分は右下へ配置して重複を避ける。一覧・詳細でもお気に入り／ごみ箱の操作を常時利用できる。
- メディア右クリックメニューの「プロパティ」は、そのファイルのタグ、形式、MIME、サイズ、寸法、再生時間またはページ数、更新／登録日時、保存場所を表示する。
- プロパティとビュワーのファイル情報は同じ表示部品を利用する。対象1件のメタデータを取得し、動画再生やレコメンド検索を開始しない。Escape、閉じるボタン、背景クリックで閉じる。
- プロパティのタグは読み取り専用。未取得のページ数は「未取得」と表示する。
- 小さい説明文・補助情報を原則12px以上へ拡大し、本文とファイル名も拡大する。タイル寸法と仮想スクロールを維持し、必要な行高・余白を調整する。

## ビュワー

- 初期状態では情報・レコメンドを右端のバーへ、一覧を下端のバーへ格納する。フローティングでの最小表示は移動できる丸いアイコンを維持する。
- 一覧と情報・レコメンドをドラッグ中は、移動予定の辺またはフローティング位置へ同じ半透明枠と「○ …へ移動」を表示する。プレビューはパネル外のビュワー領域を基準に配置し、元のドッキング位置の変形に影響されない。
- 画像倍率と拡大／縮小・等倍・全体表示を上バーの中央へ配置する。
- 右開きのブックに合わせ、次ページ／次の本を左、前ページ／前の本を右へ配置する。
- 同じ一覧内で別ファイルを開いても一覧パネルを再マウントしない。保持済みのページとスクロール領域を再利用し、現在ファイルに追従する。未取得の範囲のみ必要に応じて読み込む。

## 動画削除と描画

- 動画をごみ箱へ移動する前に、そのメディアを保持する全libVLCセッションの終了を待つ。終了中のセッションは完了まで参照可能に保ち、同時に届いた終了・削除要求がファイル解放を待たずに進まないようにする。
- ファイル解放の待機とごみ箱処理はワーカーで行い、WebViewのUIスレッドを停止しない。終了待機がタイムアウトした場合は削除を強行せず再試行できるエラーを返す。
- ネイティブ動画は親要素のクリップ領域と操作バー・一覧・パネル・移動先プレビューを考慮し、映像がその外側や上へはみ出さないよう切り抜く。

## XのGIF中間ファイル

- `.投稿名.UUID.gif-source.mp4`は、XのGIFとして配信されるMP4をGIF保存するための中間ファイルである。
- 新規中間ファイルはメディア保存先ではなくアプリ管理の`x-gif-sources`キャッシュへ置く。変換成功後に削除する。失敗・中断時は復旧用に保持し、7日経過後に起動時または次回ダウンロード時の保守で削除する。
- 自動削除はアプリ管理ディレクトリー内の識別可能な中間ファイルに限定する。従来版がメディアフォルダーへ残したファイルは自動削除しない。
- 従来形式に一致するUUID付き中間MP4はメディアとして列挙しない。既に登録されたものも起動時に非表示へ照合する。通常のドット始まりの動画を一括除外しない。

## 詳細検索

- ダイアログはヘッダー、残り高さのスクロール領域、フッターに分ける。文字の拡大や小さい画面でも最終項目へスクロールでき、フッターが内容を覆わない。
- タグ一覧内の最後のタグを選択し、検索へ反映できる。

## 確認方法と未確認事項

CLI、Rust試験、合成データを使ったヘッドレスChromiumで確認する。PC画面操作禁止の運用規則に従い、実画面の操作・スクリーンキャプチャ・インストーラーGUIは確認しない。コード署名証明書がないためWindowsインストーラーはAuthenticode未署名。

## 検証結果

- Rust全体は191件、Windows統合試験は1件合格。AIモデル、ライブX接続、別途動画サンプルを要する9件を除外した。
- 2つの実Windowsファイルハンドルを使い、並行した再生終了とごみ箱移動の待機が全ハンドル解放前に完了しないことを確認した。
- 中間ファイルの期限切れ整理、既存利用者ファイルの保持、1,000件の非表示レコードが欠落ファイル復旧で誤復元されないことを確認した。
- 詳細検索は6画面サイズで最後のタグの選択とフッター非重複を確認した。プロパティと一覧・詳細表示は3画面サイズ（760×600、1024×600、1440×900）で左上アイコン、操作ボタン、長いファイル情報の折り返しを確認した。
- ファイルシステム画面も6画面サイズでタイル、文字、操作ボタン、スクロールを確認した。22万件相当の起動・スクロール試験では30回の小スクロールでカードの再描画と追加ページ問い合わせがともに0件だった。
- Explorer起動試験では画像の先行表示、同一フォルダー内の既知ファイルを開く際の一覧保持、深い位置への追従、閉じた後のフォルダー復元に合格した。
- ビュワーは20テーマの情報表示、マウス／タッチ／キーボード操作、移動先プレビューの実座標、一覧DOMとサムネイル要求の保持、ブック送りの順序を確認した。動画ブリッジは親要素の切り抜き、操作領域の保護、終了再試行を確認した。
- 本番ビルドの初期JavaScriptは317.8 KiB（gzip 99.3 KiB）、初期CSSは118.0 KiB（gzip 22.5 KiB）。起動時の容量上限は据え置き、遅延読込のプロパティ等の追加分を含む総容量上限だけ14 KiB増やした。実測総容量2,661.4 KiBは更新後の上限2,668 KiB以内。
- Windowsインストーラー生成、版数／EXEメタデータ検査、生成済みNSISの関連付け4試験に合格。配布用599ファイルを`release/0.7.0`へコピーし、コピー元・先のSHA-256一致を確認した。
