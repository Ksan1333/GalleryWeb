# PixVault for Windows 0.7.0

再生中の動画削除、動画のはみ出し、パネル移動先表示、詳細検索のスクロールを修正しました。ギャラリーの右クリックからファイルのプロパティを確認できます。

## 変更内容

- 再生中・終了待ち・音量解析中の動画ファイルを解放してからごみ箱へ移動。終了タイムアウト後の再試行にも対応。
- ネイティブ動画を表示領域で切り抜き、一覧や操作バーへ重ならないよう修正。
- レコメンドは右端、一覧は下端のバーへ初期格納。ドッキング中のドラッグでも移動先に半透明の枠を表示。
- 画像倍率操作を上バー中央へ配置し、右開きのブックに合わせてページ送り・本送りの左右を反転。
- 同じ一覧内で別ファイルを開く際は一覧を保持。既知の同一フォルダー内ファイルをExplorerから開く場合も保持済み範囲を再利用。
- 右クリック「プロパティ」に共通のファイル情報を表示。
- メディア種類アイコンをサムネイル左上へ移動し、全体の小さい文字を拡大。
- 詳細検索を最後のタグまでスクロール可能にし、固定フッターとの重なりを解消。
- XのGIF保存用中間MP4をアプリ内キャッシュへ移動。成功時は削除、失敗・中断分は7日経過後の保守処理で削除。旧版が利用者フォルダーへ残した中間MP4は削除せず、ギャラリーの列挙から除外。

## 確認内容・既知の制限

TypeScript、本番ビルド、Rust、Windowsのファイル解放、合成データによるヘッドレスUI・動画ブリッジ・外部ファイル起動・22万件相当の起動／スクロール、NSISファイル関連付けとSHA-256を確認しています。

PC画面を操作しないプロジェクト規則により、実画面での操作感とインストーラーGUIは未確認です。コード署名証明書がないためインストーラーはAuthenticode未署名です。AIモデル・ライブX接続・別途用意する動画を必要とする環境依存試験は除外しています。

Rust 191件とWindows統合1件が合格（環境依存9件を除外）。生成済みNSISのファイル関連付け4件、初期読込と総アセットの容量検査も合格しました。

## ダウンロード

Windows 10/11 x64では添付の`PixVault.for.Windows_0.7.0_x64-setup.exe`を実行してください。`vlc-3.0.23.tar.xz`は同梱libVLCの対応ソースで、通常のインストールには不要です。

- インストーラー容量: 56,548,670 bytes
- SHA-256: `1983af4405d7186e96168bc924a24f5fe587aeefde758fafadea9ddaa9dd1121`
- `SHA256SUMS.github`は公開ファイル名用、`SHA256SUMS`は保管済み配布物全体用です。
